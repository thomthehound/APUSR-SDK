# Distribution license copies

This directory contains license texts that APUSR packaging may need to place
beside redistributed components.

- `Apache-2.0.txt` — original APUSR work.
- `FidelityFX-MIT.txt` — the audited AMD FidelityFX SDK 2.0.0 / FSR 4.0.2
  snapshot used by retained reference and derived payload material.
- `Detours-MIT.txt` — the vendored Microsoft Detours 4.0.1 dependency.
- `WinPixEventRuntime-MIT.txt` — the audited Microsoft MIT license for current
  WinPixEventRuntime distributions. Profiling packages additionally require and
  copy the exact license file belonging to the selected runtime package.

These files do not relicense third-party material. See
`../THIRD_PARTY_NOTICES.md` and `../docs/development/licensing.md` for provenance
and redistribution policy.
