# APUSR experiments

This tree contains preserved research artifacts that are intentionally outside
the product build, shipping shader dependency graph, and quality product test
set. An experiment must not be treated as product behavior merely because it is
kept in the repository.

- `rdna2_dp4a_compat/` preserves the retired DX12 FSR4 INT8 packed-DP4A
  dependency-scheduling compatibility work and its measured newer-hardware cost.
