# Test data provenance

`fsr4_vulkan_p459.pack` is a compiled Vulkan shader-pack fixture generated from
APUSR's maintained FSR4 INT8 reference shader path. The shader payload derives
from the FidelityFX SDK 2.0.0 / FSR 4.0.2 MIT-licensed reference material, so
the compiled fixture is distributed under the same MIT terms. See
`LICENSE-FidelityFX-MIT.md`.

The adjacent JSON file is APUSR-generated manifest metadata describing that
fixture. `p459` is a shader permutation key, not an APUSR release or private
repository version.
