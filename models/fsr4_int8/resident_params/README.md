# Resident FSR4 parameter arenas

The binary arenas in this directory are generated transformations of the FSR4
INT8 parameters imported from the AMD FidelityFX SDK 2.0.0 / FSR 4.0.2
reference snapshot. The source parameter payload is MIT-licensed; the generated
arenas retain that provenance and are distributed under the same MIT terms.

The packing/layout code that generates these arenas is APUSR work and remains
Apache-2.0. The numerical parameter content is not claimed as original APUSR
model authorship.

See `LICENSE.md` and `../reference/README.md`.
